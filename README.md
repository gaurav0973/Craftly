# Craftly 95: Make AI Mediocre Again

> **Craftly is an AI website builder that generates pure HTML/CSS/JavaScript.**

Craftly brings back the pure fundamentals of web development. Instead of churning out megabytes of bloated JavaScript bundles, complex build tooling, and endless dependency trees, Craftly AI writes clean, handcrafted `index.html`, `style.css`, and `script.js` directly from natural language prompts.

---

## 🌟 Key Features

- **Pure HTML/CSS/JS**: Zero build steps, zero `node_modules` overhead, instant loading.
- **Craftly 95 Retro UI**: Authentic Windows 95 / early web aesthetics with beveled windows, status bars, and classic toolbars.
- **AI-Powered Code Generation**: Natural language prompt-to-code compiler that produces semantic HTML5, modern CSS3, and vanilla JavaScript.
- **Live Sandbox Preview**: Instant real-time iframe sandbox testing and full code inspection view.
- **Downloadable Source Files**: Directly inspect, copy, or export individual `.html`, `.css`, and `.js` source files.

---

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh/) or [Node.js](https://nodejs.org/) (v18+)
- PostgreSQL Database
- Clerk API Keys
- Gemini API Key

### Running Locally

```bash
# Install dependencies
bun install

# Run database migrations
bunx prisma db push

# Start the development server
bun run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.
